# 要件概要

## 目的

放送中のアニメ（今期）を、ドラッグ&ドロップで S〜F にランク付けした「ティア表」を誰でも簡単に作り、保存・公開・SNS 共有できるサイトを提供する。公開されたティア表を集計して「みんなの評価」を出し、検索流入（SEO）と広告で収益化する。

## 想定する利用者

| 利用者 | したいこと |
| --- | --- |
| アニメ視聴者（未ログイン） | 今期のティア表をすぐ作って画像で保存・共有したい。みんなの評価を見たい |
| アニメ視聴者（ログイン） | 季節ごとにティア表を保存し、あとから編集・公開したい |
| 検索・SNS からの訪問者 | 作品や季節の評価、他人のティア表を見たい |
| 権利者 | 作品情報・画像の掲載停止を依頼したい |
| 運営者 | 作品データの更新を自動化し、少ない手間と費用で運用したい |

## 機能要件

### 作品データ

- 季節（冬 1〜3 月・春 4〜6 月・夏 7〜9 月・秋 10〜12 月）ごとに、放送中のアニメ一覧を持つ
- 前の季節から続く 2 クール目の作品も今期に含める
- 一覧は GitHub Actions が毎週自動で取得し、PR を作成して CI が通れば自動マージ → 自動デプロイする
- 作品名の修正・非表示・画像の非表示を手動で上書きでき、自動更新で上書きされない

### ティア表

- 標準は S・A・B・C・D・E・F の 7 段階。段の名前・色・数（1〜10 段）は自由に変えられる
- PC はドラッグ&ドロップ、スマホはタップ（カードを選んで行をタップ）で操作できる。キーボードでも操作できる
- 未ログインでも作成でき、作業内容は端末に自動保存される。PNG 画像としてダウンロードできる
- ログインすると保存できる。公開範囲は「非公開」「リンクを知っている人のみ」「公開」
- 公開・限定公開のティア表は固有 URL を持ち、OGP 画像付きで X・LINE・Bluesky に共有できる
- 年・季節ごとに何個でも作れる

### 集計

- 「公開」のティア表だけを集計し、作品ごとの平均点（0〜100）と S〜F の分布を出す
- 季節ページと作品ページにランキングとして表示する

### アカウント

- Google ログインと、メールのログインリンク（パスワードなし）に対応する
- ユーザー名・表示名を変えられる。退会するとティア表と集計への寄与も消える

### その他

- 利用規約・プライバシーポリシー（電気通信事業法の外部送信規律に沿った公表を含む）・削除依頼フォーム
- 広告（Google AdSense）枠。審査前は表示しない

## 非機能要件

| 項目 | 要件 | 実現方法 |
| --- | --- | --- |
| 負荷・費用 | アクセスが急増しても低コストで耐える | Cloudflare Workers・D1・R2。閲覧ページはエッジキャッシュ、エディタは静的ファイル、保存時だけ書き込み |
| 表示速度 | スマホで速く表示する | 静的生成と SSR の使い分け、画像は WebP の小さいサムネイル、JS はエディタのみ |
| SEO | 季節・作品・ティア表ページを検索に載せる | 各ページの title / description / canonical / 構造化データ / サイトマップ。中身の薄いページは noindex |
| セキュリティ | 不正な書き込みやなりすましを防ぐ | CSRF（Origin 確認）、レート制限、Turnstile、セッションはハッシュで保存、入力の検証 |
| 保守性 | 作品データ更新に人手をかけない | 週次の自動取得 → PR → CI → 自動マージ → 自動デプロイ |
| アクセシビリティ | キーボード・読み上げで使える | キーボード操作、aria 属性、色だけに頼らない表示 |

## 法務上の前提

- 作品画像の利用は権利確認が取れるまで行わない。そのため **画像を使わない文字カード方式（既定）** と **画像方式** の 2 つを実装し、環境変数 1 つで切り替える（[operations.md](operations.md#画像モードの切り替え)）
- 作品データの取得元は AniList API。商用利用になるため、本番公開前に利用規約を確認する
- 権利者からの依頼は削除依頼フォームで受け付け、`data/overrides.json` で即時に非表示・画像非表示にできる
- 外部送信（Google ログイン・Turnstile・AdSense など）はプライバシーポリシーで公表する
