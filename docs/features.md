# 機能概要

## 画面一覧

| URL | 内容 | 生成方法 |
| --- | --- | --- |
| `/` | トップ。今期への導線、新着ティア表 | SSR（エッジキャッシュ 5 分） |
| `/seasons` | 季節一覧 | 静的 |
| `/seasons/{年}/{季節}` | 季節ページ。みんなの評価ランキング、作品一覧、新着ティア表 | SSR（10 分） |
| `/seasons/{年}/{季節}/edit` | ティア表エディタ。`?list={ID}` で既存のティア表を編集 | 静的 + React |
| `/anime/{slug}` | 作品ページ。季節ごとの評価 | SSR（30 分） |
| `/t/{ID}` | ティア表の公開ページ | SSR（1 分） |
| `/lists` | みんなのティア表（新着） | SSR（2 分） |
| `/u/{ユーザー名}` | ユーザーの公開ティア表一覧 | SSR（2 分） |
| `/me` | マイページ（自分のティア表の一覧・削除） | SSR（キャッシュなし） |
| `/settings` | ユーザー名・表示名の変更、退会 | SSR（キャッシュなし） |
| `/login`, `/auth/verify` | ログイン、メールのリンクの確認 | 静的 |
| `/about`, `/terms`, `/privacy`, `/takedown` | 説明・規約・ポリシー・削除依頼 | 静的 |
| `/og/t/{ID}.png`, `/og/site.png` | OGP 画像 | 生成して R2 に保存 |
| `/sitemap.xml`, `/robots.txt`, `/ads.txt` | クローラー向け | SSR |

キャッシュの秒数は未ログインのアクセスに対するものです。ログイン中はキャッシュを使いません。

## ティア表エディタ

- 標準のティアは S〜F の 7 段（[ランクの目安](#ランクの目安)）。行の左端を押すと名前・色・並び順の変更と削除ができる。最大 10 段
- 未分類の作品は下のトレイに並び、作品名で絞り込める
- 操作方法
  - マウス: ドラッグ&ドロップ（行の間、行の中の並べ替え）
  - タッチ: 長押しでドラッグ、またはタップで選んで移動先の行をタップ
  - キーボード: Space で持ち上げ、矢印で移動、Space で置く
- 作業内容は `localStorage`（`tier-draft:{季節ID}:{ティア表ID|new}`）に自動保存。ログイン後に復元される
- 「画像をダウンロード」でブラウザ内の Canvas から PNG を作る（サーバーを使わない）
- 保存時は版番号を送り、別の端末で先に保存されていたら競合として知らせる
- 画像モードのときは「文字で表示」に切り替えられる

### ランクの目安

| ランク | 意味 |
| --- | --- |
| S | 神作・今期の覇権。今期でいちばん |
| A | 名作。毎週の放送が待ち遠しい |
| B | 良作。安定して面白い |
| C | 普通。時間があれば見る |
| D | いまいち。好みが分かれそう |
| E | 微妙。途中で止まりそう |
| F | 合わなかった。視聴をやめた |

定義は `src/lib/tierlist.ts` の `TIER_MEANINGS` にあり、エディタの下と `/about` に表示しています。

## 公開範囲

| 値 | 表示 | 公開ページ | 一覧・検索 | 集計 |
| --- | --- | --- | --- | --- |
| `private` | 非公開 | 本人のみ | × | × |
| `unlisted` | リンクを知っている人のみ | 誰でも | ×（noindex） | × |
| `public` | 公開 | 誰でも | ○ | ○ |

公開でも、作品を 5 つ以上置いていないティア表は検索に載せません（noindex）。

## 集計（みんなの評価）

1. 公開ティア表ごとに、作品を置いた行の相対位置を 0〜100 点にする。空の行は数えないので、使った行の最上段が 100 点、最下段が 0 点になる
2. 点数を S〜F の 7 段階に振り分ける（100 点が S、0 点が F、間はいちばん近い段）。段数を変えたティア表も同じ基準で数える
3. 保存・公開範囲の変更・削除のたびに、前後の差分だけを `anime_stats` に加減算する（全件の再集計はしない）
4. 平均点 = 合計点 ÷ 票数。季節ページは票数 1 以上の作品を平均点順に表示し、作品ページは票数 5 未満なら noindex

計算は `src/lib/tierlist.ts`（`contributions` / `statDeltas`）にあり、単体テストがあります。

## 認証

- **Google ログイン**: OAuth 2.0 の認可コードフロー + PKCE。state と verifier は短命の Cookie に入れる
- **メールのログインリンク**: 15 分有効の 1 回限りのリンクを Resend で送る。メールのリンクを開くと確認ボタンのページを出し、押したときにログインする（メールのリンク先を自動で開くセキュリティ製品で消費されないため）
- 同じメールアドレスなら Google でもメールでも同じアカウントになる
- セッションは 30 日。残り 15 日を切ったら延長する。DB にはトークンのハッシュだけを保存する
- `li` Cookie（ユーザー名だけ、HttpOnly ではない）で、キャッシュされたページでもヘッダーのログイン表示を切り替える

## 共有

- 公開ページの URL を X・LINE・Bluesky・端末の共有メニューで送れる
- OGP 画像は版ごとに 1 回だけ生成して R2 に保存（`og/t/{ID}-{版}.png`）。編集すると版が上がり、新しい画像になる
- 画像モードのときは OGP 画像にもサムネイルが入る

## 画像の表示方式

| モード | 作品の表示 | 画像配信 |
| --- | --- | --- |
| `text`（既定） | 作品タイトルを色付きのカードで表示（色は作品 ID から決まる） | `/img/` は 404 |
| `image` | R2 の WebP サムネイル。利用者は「文字で表示」も選べる | `/img/{key}` から 1 年キャッシュで配信 |

## 削除依頼

`/takedown` のフォームから送られた依頼は D1 の `takedown_requests` に入ります（Turnstile とレート制限あり）。対応方法は [operations.md](operations.md#削除依頼への対応) を見てください。

## 広告

`PUBLIC_ADSENSE_CLIENT` と広告ユニット ID が両方設定されているときだけ広告枠を出します。スクリプトは操作を妨げないよう遅れて読み込みます。エディタには広告を出しません。
